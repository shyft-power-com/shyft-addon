# Home Assistant Shyft Add-on repository

This repository stores the home assistant shyft addon.

[![Open your Home Assistant instance and show the add add-on repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fshyft-power-com%2Fshyft-addon)

Falls der Button nicht funktioniert, in Home Assistant unter **Einstellungen → Add-ons → Add-on Store → ⋮ → Repositories** diese URL eintragen:

```
https://github.com/shyft-power-com/shyft-addon
```
